## Descripción del Repositorio

Este repositorio contiene la solución a los 5 ejercicios prácticos correspondientes al Primer Parcial. El objetivo de estas prácticas es fortalecer los fundamentos de programación en **C++**, abarcando desde tipos primitivos, operadores y sentencias de control, hasta la manipulación de cadenas de texto y el diseño de clases encapsuladas con interacción entre objetos.

-----------------------------------------------------------

## Estructura del Proyecto

Los archivos fuente (`.cpp`) están organizados en el directorio raíz del proyecto con la siguiente nomenclatura:

```text
Practicas_P1/
├── Console_Calculator.cpp         # Ejercicio 1: Calculadora de Consola
├── Classifier_Control_Statements.cpp # Ejercicio 2: Clasificador de Calificaciones
├── String_Processor.cpp            # Ejercicio 3: Procesador de Cadenas
├── First_Class.cpp                 # Ejercicio 4: Clase Estudiante
├── Object_Interaction.cpp          # Ejercicio 5: Interacción entre Objetos (Grupo)
└── README.md                       # Documentación del proyecto

## Resumen de ejercicios


01 - Console_Calculator.cpp === Uso de tipos primitivos, estructura switch y validación explícita de división entre cero.
02 - Classifier_Control_Statements.cpp === Evaluación de calificaciones mediante estructuras condicionales anidadas (if-else).
03 - String_Processor.cpp === Conteo de vocales mediante iteración de arreglos, procesamiento de palabras con stringstream e inversión de texto con <algorithm>.
04 - First_Class.cpp, === Encapsulamiento con miembros private y public, constructores con this-> y métodos de verificación de estado.
05 - Object_Interaction.cpp === Composición de objetos, arreglos de objetos (Estudiante[5]) y cálculo del promedio general de un grupo.
